🌡️ Temperature Converter Program

A simple, user-friendly Python program that converts temperatures between Celsius and Fahrenheit. This project was developed as part of an internship task to demonstrate foundational programming logic and user input handling. 🚀

✨ Features

Celsius to Fahrenheit Conversion: Effortlessly convert temperature input from Celsius to Fahrenheit. 🌡️

Fahrenheit to Celsius Conversion: Quickly convert temperature input from Fahrenheit to Celsius. ❄️

User-Friendly Interface: Clear command-line menu for easy interaction. 💻

Precision: Results are automatically formatted to two decimal places for accuracy. 🎯

🛠️ Prerequisites

Python 3.x installed on your system. 🐍

🚀 How to Run

Clone this repository or download the temperatureconverter.py file. 📥

Open your terminal or command prompt. ⌨️

Navigate to the folder where the file is located. 📂

Run the following command:

bash 

python temperatureconverter.py
